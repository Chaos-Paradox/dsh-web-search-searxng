# 「检查更新」按钮是怎么工作的？

**中文版** | [English](update-check.md)

这篇文章用大白话解释插件设置卡片上「检查更新」按钮的来龙去脉。你不需要任何编程知识。

## 一句话总结

> **你不点，它不动。** 只有你亲手点下「检查更新」按钮的那一刻，插件才会去网上问一句："现在这个插件的最新版本是多少？"——除此之外，它绝不主动联网。

## 它在卡片上的样子

打开 **设置 → 插件 → SearXNG 搜索**，在输入框下方有一行：

```
当前版本: v0.1.0   [检查更新]
```

- **当前版本**：你机器上实际安装的这个插件的版本号。
- **检查更新**：一个按钮，点它才会开始检查。

## 点击之后，它具体做了什么？

整个过程就像打电话问一件事，说完就挂：

1. **问**：向插件在 GitHub 上的"发布页面"问一个问题——"最新发布的版本号是多少？"
   - 这个问题里**只包含插件的名字**，不包含任何关于你的信息：不带上你的搜索内容、不带上你的电脑信息、不带上你的设置。
2. **答**：发布页面回答一个版本号，比如 `v0.2.0`。
3. **比**：插件把这个数字和你机器上的版本号（比如 `0.1.0`）比一比大小。
4. **说**：把比较结果告诉你（见下文三种结果）。

问完这一次就结束了。**它不会每隔一段时间自己偷偷去问，也不会在你打开设置页时顺手去问。**

## 三种结果分别是什么意思？

| 你看到的话 | 意思 | 你需要做什么 |
|---|---|---|
| **发现新版本：v0.2.0 …** | 网上有比你机器上更新的版本 | 想更新就照提示操作（见下一节）；不想更新就忽略，插件照常工作 |
| **已是最新版本。** | 你机器上的就是最新的 | 什么都不用做 |
| **暂时无法访问 GitHub 发布页…** | 这次"打电话"没打通（没联网、网络不通、或对方太忙） | 不影响任何功能，稍后再点一次试试即可 |

## 发现新版本后，怎么更新？

卡片会同时给出「发布说明」链接（可以看到新版本改了什么）和更新方法。更新有两条路，任选其一：

- **命令行**（复制一行命令即可）：
  ```sh
  dsh plugin --profile <你的配置名> update dsh-web-search-searxng
  ```
- **图形界面**：在「插件」页把这个插件卸载，再重新添加一次。

不管走哪条路，**更新后都要重启一次应用**才会用上新版本。

## 为什么不自动更新？

这是故意的，是为了保护你：

- **你的机器你做主**：更新意味着换掉正在运行的程序。插件不会在背后悄悄替换自己，任何变化都由你亲手发起。
- **出问题时找得回现场**：如果新版本有毛病，"上次是你自己点了更新"这个事实能帮你快速定位原因。

## 常见疑问

**问：不点按钮，它会不会自己联网？**
不会。卡片打开、翻页、放着不管，都不会产生任何网络请求。这一点有自动化测试专门把关（测试会检查"渲染之后零次联网"）。

**问：点按钮联网，会不会泄露我的隐私？**
不会。这次请求只问"最新版本号是多少"，不携带你的任何数据。插件本身也不需要账号、不需要密钥。

**问：我的 SearXNG 搜索和这个检查有关系吗？**
完全没有。搜索请求发往你自己的 SearXNG 实例；检查更新的请求发往 GitHub 的公开发布页。两者互不影响——就算检查更新失败了，搜索也照常工作。

**问：我一直不更新会怎样？**
不会怎样。旧版本会继续正常工作，只是享受不到新版本的改进和修复。
